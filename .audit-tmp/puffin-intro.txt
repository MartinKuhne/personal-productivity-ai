    feat(desktop): add in-app profiling with puffin_egui and Tracy instrumentation
    
    Add puffin and puffin_egui as optional dependencies gated behind a
    'profiling' cargo feature. When enabled, the application instruments
    the egui frame loop, markdown parsing, tree rendering, and tool
    execution with puffin profile scopes for live flamegraph viewing.
    
    A Profiler window (toggleable via egui::Window) shows the interactive
    puffin_egui flamegraph. Profile scopes are added to:
    - FastMdApp::update_ui (frame loop)
    - render_markdown (UI rendering)
    - parse_markdown_to_events (markdown parsing)
    - flatten_tree (directory tree flattening)
    - execute_tool (tool execution)
    
    Also adds doc/planning/perf.md with the profiling tooling plan.
    
    Dependencies:
    - puffin 0.20 (optional, feature-gated)
    - puffin_egui from git (optional, feature-gated; egui 0.35 compatible)
    
    Usage: cargo run --features profiling
