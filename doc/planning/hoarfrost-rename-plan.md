## 2. Name-specific findings for `hoarfrost`

1. **No collision in the repo.** `rg -i 'hoar|frost'` over the working tree returns
   **0 hits**. The residual-audit gate in §6 stays unambiguous: after the rename,
   `rg -i 'hoar'` finds only intended hits.
2. **crates.io is free.** `GET /api/v1/crates/hoarfrost` → **404**. The fuzzy
   search's single hit is `kylig-style` with `exact_match: false`. No published
   crate means no transitive-dependency shadowing either.
3. **Formatting impact is +1 char, no reflow.** `iced_pro`/`iced-pro` (8 chars) →
   `hoarfrost` (9). `rustfmt.toml` sets only `newline_style = "Unix"`, so
   `max_width` stays at the default 100. The longest affected import is 95 chars —
   `use iced_pro::surface::menu::model::{ActivationEffect, Menu, MenuId, RadioGroupId, submenu_id};`
   → **96 after rename, still under 100**. `wrap_comments` is unset, so doc
   comments do not reflow either. `cargo fmt --check` should be a no-op.
4. **Branding.** `hoarfrost` keeps the ice/frost lineage of `iced-pro` while
   staying clearly distinct from the upstream `iced` crate — the two names never
   blur inside a `use` statement.

## 3. Hard traps (unchanged by the new name)

1. **`iced_program` is an upstream iced crate** — 3 lines in `Cargo.lock`
   (`:2473`, `:2524`, `:2593`). `iced_pro` is a literal prefix of it, so a blind
   replace yields `hoarfrostgram`. Use a negative lookahead (`\biced_pro(?!gram)`)
   or mask-and-restore.
2. **Prose false positives.** `iced provides` (`doc/iced.md`) and `iced promotes`
   (`src/app/ui_iced/attributions.rs:439`) match a loose `iced[-_. ]?pro` regex.
   Match only the two exact strings `iced-pro` and `iced_pro`.
3. **`src/app/ui_iced/` and `tests/iced_visual/` are NOT the crate.** They name
   the upstream iced rendering layer. Renaming them is out of scope and would be a
   much larger, unrelated refactor.
4. **`src/iced-pro/spec.md` contains no `iced-pro` string** — see the header
   block. Satisfies `RUST-043`.
5. **Persisted user data is safe.** `storage_key()` returns
   `format!("movable:{}", id.as_str())` (`src/iced-pro/surface/movable.rs:616-618`),
   and `group_for` the same rule (`:625-627`). No crate name appears in on-disk
   keys, so **no user-config migration is required** — in either direction.
6. **A test hard-codes the crate name.** `src/app/ui/attributions_tests.rs:58`
   (`"src/iced-pro/Cargo.toml"`) and `:71` (`"iced-pro"` in the workspace-member
   exclusion set). Miss these and the About-dialog attribution test fails.
7. **Uncommitted work in the tree at baseline** — 3 untracked files:
   `src/iced-pro/geometry/pane_solver.rs`, `pane_solver_tests.rs`,
   `window_geometry.rs`. Commit or stash before any `git mv`.
8. **Report/label strings that read as the product name** and should change with it:
   `src/iced-pro/token_lint.rs:982` (`render_scoped("iced-pro", …)`),
   `src/iced-pro/spec_coverage.rs:466` (coverage-ledger header),
   `src/iced-pro/gallery_audit.rs:276`, `src/iced-pro/bin/gallery.rs:172`.
9. **Doc-comment cross-links to the ledger.** 8 inbound references to
   `doc/planning/iced-pro-tasks.md` from code doc comments (`src/iced-pro/mod.rs:15`,
   `focus.rs:11`, `state.rs:11`, `Cargo.toml:35`, `token/typography.rs`,
   `token/contrast.rs`, `surface/input_dialog.rs`, `src/app/ui/theme.rs`) plus one
   internal cross-link in `iced-pro-handoff.md`. These break silently if D-1 is
   taken and the links are not fixed.

## 5. Execution sequence

### Phase 0 — safety

1. `git switch -c chore/rename-iced-pro-hoarfrost` off the current line.
2. Commit or stash the 3 untracked `geometry/` files.
   **Gate:** `git status --porcelain` is empty.
3. Record the baseline test count (`cargo nextest run --workspace`) so the
   post-rename result is comparable rather than merely green.

### Phase 1 — move the directory (structure only, no content edits)

4. `git mv src/iced-pro src/hoarfrost` — 335 tracked files, rename-only diff, no
   case-only-filesystem hazard (the names differ by more than case).
5. `Cargo.toml`: member `"src/hoarfrost"`, dependency
   `hoarfrost = { path = "src/hoarfrost" }`.
6. `src/hoarfrost/Cargo.toml`: `name = "hoarfrost"`, updated description (D-2).
7. **Gate:** `cargo check -p hoarfrost` — any failure should come from the *app*
   crate's `use iced_pro::`, none from the framework crate itself.

### Phase 2 — mechanical identifier sweep

8. Repo-wide replace across the 93 files, in this order:
   mask `iced_program` → placeholder → `iced-pro`→`hoarfrost`,
   `iced_pro`→`hoarfrost` → restore placeholder.
9. Do **not** touch: `src/hoarfrost/spec.md`, any `SPEC.md`, `target/`, `.git/`.
10. **Gate:** `cargo check --quiet` clean; `cargo tree -p hoarfrost` and
    `cargo tree -i hoarfrost` show the expected wiring; `Cargo.lock` regenerated
    with `hoarfrost` and an **intact** `iced_program`.

### Phase 3 — residual-name audit (the gate that actually matters)

11. `rg -n '\biced[-_]pro' --glob '!target/**' --glob '!.git/**'` → expected
    **zero** (or only the D-1 docs, if they are left as-is).
12. `rg -n 'frost' Cargo.lock` → confirm `iced_program` is present and uncorrupted.
13. Confirm `ui_iced` / `iced_visual` were not renamed:
    `git diff --stat --name-only | rg 'ui_iced|iced_visual'` shows content-only
    edits at most, no renames.
14. Positive check: `rg -ni 'hoar' --glob '!target/**'` returns only the intended
    ~93 files.

### Phase 4 — quality gate (repo root, per `AGENTS.md`)

15. `cargo check --quiet`
16. `cargo nextest run --status-level fail --show-progress none` — expect the
    **same test count** as the Phase 0 baseline
17. `cargo clippy -- -D warnings`
18. `cargo fmt --check` — should be a no-op given the +1 char / `max_width` 100
    headroom in §2.3
19. `cargo doc --no-deps --quiet` — catches broken intra-doc links across the 221
    doc-comment lines; this is the likeliest breakage in the whole change

### Phase 5 — runtime smoke

20. `cargo run -p hoarfrost --bin gallery -- <tmp>` — exercises the renamed bin
    target and the temp-dir path (D-3).
21. Launch `fastmd`, open **About** → the third-party list must **not** list
    `hoarfrost` (workspace-internal exclusion, `attributions_tests.rs:61-75`), and
    movable-overlay geometry must still restore from existing persisted state
    (§3.5).

### Phase 6 — docs

22. Update `doc/technical-context/ARCHITECTURE_C4.md` — mandatory under
    `RUST-040`/`RUST-041`: PlantUML node ids `iced_pro`→`hoarfrost` (`:68`,
    `:74`, `:75`), labels `"iced-pro"`→`"hoarfrost"`, the `Component(pro, …)`
    node (`:216`), and the §"Component Diagram (Level 3)" heading and paths
    (`:513-539`).
23. Apply D-1 to the planning docs and fix the 9 links listed in §3.9.

### Phase 7 — housekeeping

24. If a local `.codegraph/` index exists, re-index after the move. The committed
    `.codegraph/` holds only a `.gitignore`, so likely nothing to do.
25. Leave `target/` alone — a full `cargo clean` costs a long rebuild for no
    correctness gain.
26. PR title `chore: rename iced-pro crate to hoarfrost`; state explicitly that
    git history retains the old name by design (D-4).

## 8. Effort and risk

~93 files, mostly mechanical. The risk concentrates in three places, in order:

1. **Intra-doc links** — 221 doc-comment lines reference `iced_pro::…` paths;
   caught only by `cargo doc` (Phase 4 step 19).
2. **`attributions_tests.rs` hard-coded names** — a green build with a wrong
   About-dialog exclusion is possible if §3.6 is missed.
3. **`iced_program` corruption** — silent until a dependency-resolution error;
   guarded by the Phase 3 step 12 check.
